# 测试版安装与验收状态

本项目仅适用于说明中的郑州超算平台，属于非官方项目。`v0.5.0-beta.1` 已作为公开预发布测试版提供；维护者接受当前实测范围及已知限制，未标为稳定版。安装包、校验清单与扩展见[固定版本下载页](https://github.com/pancake-github/zzu-nscc-helper/releases/tag/v0.5.0-beta.1)。

## 安装与首次启动

1. Windows 11 x64 使用者选择在线或离线安装器，按 Release 中的 `SHA256SUMS.txt` 核对 SHA-256；安装器未做 Authenticode 数字签名，可能显示发布者未知。
2. 在安装器中选择保活、分流、SFTP 的任意非空组合。程序包含运行库，无需安装 Python；Clash 和平台 VPN 客户端需要自行安装。
3. 从桌面入口启动助手。仅安装分流或 SFTP 时可直接使用对应界面；任务需要手动开始，分流需要先预览再应用。
4. 保活首次使用：在 Edge 的 `edge://extensions` 开启开发人员模式，选择“加载解压缩的扩展”，选择安装目录的 `modules/zzu_nscc_helper/keepalive/extension` 文件夹；默认位于 `%LOCALAPPDATA%/Programs/ZZU-NSCC-Helper` 内。目录选择器只显示子目录，看不到文件并不代表目录为空。确认出现“SSL VPN 助手 · Edge 标签页连接器”卡片并启用，且助手实际显示连接就绪。单独提供的扩展 ZIP 也可解压到长期保留的文件夹后加载。
5. 自行登录平台 VPN，打开本平台计算服务或 E-File 页面，在助手内选择具体标签页并绑定开始。建议使用专用标签页；绑定标签页导航到其他地址会停止，切换到其他标签页不改变绑定。软件版本为 0.5.0-beta.1，扩展连接协议版本仍为 0.4.0。

SFTP 使用自己的 SSH 账号，密码只在本机隐藏输入。保活不自动登录或重新连接 VPN，也不保证网页 SSO 会话永不过期。

## Edge 连接组件 0.4.1 修复

平台可能把 E-File 或计算服务地址改写为带 `;jsessionid=…` 的地址。连接组件 0.4.0 对路径作严格字符串比较，会将这些正常页面误标为“仅查看”。0.4.1 只增加对该平台单个 32 位十六进制会话参数的支持，保留原 HTTPS 地址、端口和两个页面路由限制。绑定与恢复保留完整原网址；导航到其他地址、会话值改变及恢复页面校验失败仍停止。无需删除会话参数或重新登录来规避识别问题。

主程序版本仍为 0.5.0-beta.1，组件修订号为 0.4.1，本机通信协议仍为 0.4.0，因此可直接配合已有主程序使用。既有安装器及其校验和保持原样，仍包含旧组件；首次安装、重装或覆盖升级这些安装器后，需要补装本修复。源代码后续构建会包含新组件。

1. 在助手中停止保活，下载 [0.4.1 组件 ZIP](https://github.com/pancake-github/zzu-nscc-helper/releases/download/edge-v0.4.1/zzu-nscc-helper-edge-0.4.1.zip)，并按同一[修复发布页](https://github.com/pancake-github/zzu-nscc-helper/releases/tag/edge-v0.4.1)的 `SHA256SUMS.txt` 核对 SHA-256。
2. 在 Edge 扩展卡片的“详细信息”中确认实际加载目录，将原目录的 `background.js` 和 `manifest.json` 备份到另一个目录，再用 ZIP 内同名文件替换。若按安装说明加载，目录为 `%LOCALAPPDATA%/Programs/ZZU-NSCC-Helper/modules/zzu_nscc_helper/keepalive/extension`。不要加载第二份相同连接组件。
3. 在 `edge://extensions` 中点击该连接组件的“重新加载”一次，确认卡片版本为 0.4.1。已有权限和扩展标识不变，不需要重新安装 Native Messaging 宿主。
4. 返回助手，点击“检查连接并刷新标签页”，选择 E-File 后点击“绑定并开始保活”。只有实际显示最近成功时间和成功次数，才算本机真实请求成功。

本修复不携带使用者的会话值、密码或 Cookie。公开测试使用离线生成的虚拟会话；修复包的离线回归不等于重新完成完整安装器矩阵或长时间真实保活验收。

## 升级、卸载和验证范围

安装器默认部署到当前用户的程序目录。三个组件可以单选、任意双选或全部安装；SFTP和分流不要求Edge扩展。在线版只下载公共运行库和选中组件，固定SHA-256不符即停止；离线版内嵌同样的四个载荷。

首次保活安装需要在Edge手动加载扩展一次；软件明确显示连接和版本，打开目录不代表扩展已安装。安装器只维护本产品在当前用户下的Native Messaging键；首次迁移先保存原注册，升级保留该备份，卸载时只有注册仍属于本安装才恢复。

本版升级支持添加组件。移除已有组件时先卸载，再选择所需组件重新安装。卸载保留本机日志、传输回执及分流备份，不自动撤销用户已经应用的Clash规则；应先在软件中预览并回滚本产品新增的内容。

安装不启动平台请求、不提交作业、不应用Clash规则、不创建开机启动。运行中的助手会阻止安装或卸载；不会强杀浏览器和传输任务。配置注册冲突会明确失败并保留本机备份。

`packaging/requirements-build.txt`只用于GitHub Actions隔离环境，不修改使用者现有Python。公共运行库包含冻结的GUI、后台和维护程序；三个业务组件位于安装目录的`modules`下，未选组件的业务代码不安装。源码、平台公钥与第三方许可证可独立审阅。
