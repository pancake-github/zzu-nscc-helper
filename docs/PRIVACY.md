# 公开发布与本机数据边界

公开仓库采用文件白名单导出，不能把整个超算工作区直接提交。

允许公开：本项目源码、测试、平台固定目标、固定主机公钥、组件契约、构建与使用说明，以及不含个人内容的验收摘要。

留在使用者电脑：用户名、密码、本机代理端口、控制器认证信息、VPN网卡身份、订阅及节点配置、应用设置、原始日志、配置备份、传输回执、下载文件及研究数据。

SFTP用户名由使用者填写，初始输入框为空。统一GUI中的密码只通过本次工作进程的私有匿名管道传递，不进入命令行参数、环境变量、临时请求文件或日志。每批任务结束后释放应用持有的密码引用；不声称能够擦除解释器、Qt或操作系统中的全部内存副本。历史基线CLI仍通过隐藏的终端输入读取密码。

活跃传输回执不再保存独立的用户名字段或密码，只记录用户选择的路径和校验结果；路径本身可能包含主目录用户名，因此回执仍属于私有数据。助手日志、原生连接清单及分流备份位于当前用户的`%LOCALAPPDATA%/ZZU-NSCC-Helper`，不写入安装目录或源码仓库。分流备份可能包含用户原有配置中的订阅与控制器认证内容，因此始终留在本机，也不自动附加到问题报告。

公开检查器分别扫描工作目录、Git暂存区和全部可达提交中的文件对象。测试已验证：即使工作目录已经删除某个认证字面量，暂存区或旧提交仍有该内容时也会阻止审核通过。检查结果只输出文件相对路径与固定错误类别，不输出疑似凭据。自动扫描仍需配合文件白名单和发布前人工复核，不能替代所有形式的秘密识别。

保活和桥接日志只保存时间、状态、耗时、响应字节数及固定错误类别，不保存浏览器完整标题、URL、Cookie、密码或网页正文。SFTP回执需要记录用户选择的文件路径和传输校验信息，它属于本机私有数据，不随问题反馈自动上传。

不收集遥测，不静默上传故障报告，不保存平台密码，不导入系统证书，不修改浏览器证书校验策略。
